# Sergio Portfolio

A modern one-page professional portfolio built with HTML5, CSS3 and vanilla JavaScript.

## Files
- `index.html` — site structure and content
- `styles.css` — responsive styling, layout, animations
- `script.js` — mobile menu, scroll reveal, active navigation

## Customize
1. Open `index.html`.
2. Replace placeholder contact links in the Contact section:
   - `your.email@example.com`
   - LinkedIn URL
   - WhatsApp number
   - Upwork/Fiverr links if needed
3. Add real project images or links in the Featured Projects section.
4. Deploy with GitHub Pages, Netlify, Vercel, or any static hosting provider.
